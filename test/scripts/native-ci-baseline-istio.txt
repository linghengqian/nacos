# Integration tests that fail in the builds with the Istio adaptor (nacos.extension.naming.istio.enabled),
# for a reason that does not depend on the Native executable: they fail against the ordinary JVM Server
# with the adaptor as well, and pass without it. Deregistering an instance that does not exist removes
# the one that the same connection has published for the service, because the Server removes by service,
# and the test expects it to stay. A query reads the cached service info, which a push task refreshes
# 500 ms later, so the test passes while the cache is stale. The adaptor reads the registry at once on
# every deregistration (NacosServiceInfoResourceWatcher), so the cache is fresh by then. The features
# scenario of test/scripts/native-ci.sh is the only one that builds the adaptor in, and the only one that
# reads this file. Same format as native-ci-baseline.txt.
